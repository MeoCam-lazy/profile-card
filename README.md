# 🎴 Profile Card - Personal Showcase

Trang **Profile Card** cá nhân giới thiệu bản thân với phong cách đơn giản, bắt mắt, tích hợp hiệu ứng chuyển động mượt mà (CSS Animation) và nhạc nền Giáng sinh/Mùa đông sôi động.

---

## 🌟 Tính năng nổi bật

- 🎨 **Giao diện hiện đại & độc đáo**: Thiết kế thẻ Profile tinh tế, màu sắc hài hòa.
- ✨ **CSS Animation**: Hiệu ứng chuyển động mượt mà cho hình ảnh và khung thông tin.
- 🎵 **Tích hợp Background Audio**: Phát nhạc nền sống động (Jingle Bells / Winter Theme).
- 📱 **Responsive Design**: Tối ưu hiển thị trên cả máy tính và thiết bị di động.
- 🔗 **Social Links**: Tích hợp trang liên kết cá nhân.

---

## 🛠️ Công nghệ sử dụng

- **HTML5**: Cấu trúc ngữ nghĩa (Semantic HTML), `<audio>` tag.
- **CSS3**: Custom styling, Flexbox/Layout, Animations & Keyframes.
- **Netlify**: Hosting & Deployment.
